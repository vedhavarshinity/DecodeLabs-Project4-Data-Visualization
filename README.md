# 📊 Project 4 – E-Commerce Data Visualization

##  Project Overview

This project focuses on analyzing e-commerce sales data and transforming raw data into meaningful visualizations and business insights.

The project uses Python, Pandas, Matplotlib, Seaborn, and Streamlit to analyze sales trends, product performance, order status, payment methods, and referral sources.

An interactive Streamlit dashboard is developed to help users explore the data using filters and view important business metrics.

---

## Project Goal

The main goal of this project is to convert raw e-commerce data into clear and actionable business insights through effective data visualization.

### Key Questions

- Which products generate the highest revenue?
- Which products have the highest quantity sold?
- How does revenue change over time?
- Which payment method generates the most revenue?
- Which referral source performs best?
- What is the distribution of order statuses?
- Which month generates the highest revenue?

---

##  Dataset

The project uses an e-commerce sales dataset containing order-level information.

### Dataset File

`Dataset/Dataset for Data Analytics.csv`

### Main Columns

| Column | Description |
|---|---|
| OrderID | Unique order identifier |
| CustomerID | Customer identifier |
| Date | Order date |
| Product | Product purchased |
| Quantity | Number of units purchased |
| UnitPrice | Price per unit |
| ItemsInCart | Number of items in the cart |
| TotalPrice | Total order value |
| PaymentMethod | Payment method used |
| OrderStatus | Current order status |
| ReferralSource | Customer referral source |

📈 Data Visualizations
1. Monthly Revenue Trend

A line chart is used to understand revenue changes over time.

2. Revenue by Product

A horizontal bar chart compares revenue generated by different products.

3. Quantity Sold by Product

A bar chart compares the quantity sold for each product.

4. Revenue by Payment Method

A bar chart compares revenue generated through different payment methods.

5. Revenue by Referral Source

A horizontal bar chart compares revenue generated from different referral sources.

6. Order Status Distribution

A bar chart shows the distribution of order statuses.

7. Order Status by Product

A stacked bar chart compares order-status patterns across products.
